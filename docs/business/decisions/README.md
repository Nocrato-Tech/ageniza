# Índice das decisões de negócio

Uma linha por decisão, agrupada por módulo. Cada decisão é um arquivo `AAAA-MM-DD-<slug>.md` nesta pasta, com o título da linha `# ` do arquivo e a data da decisão.

**Como manter.** Este índice é gerado pelo `pnpm docs:decisions-index` (`scripts/generate-decisions-index.mjs`) e não se edita à mão. Toda decisão nova entra na pasta como arquivo no PR que a cria, e esse PR não toca o índice (ver [`implementation-checklist.md`](../../implementation-checklist.md), item 12). O índice é regenerado ao fim de cada onda, num PR de docs. **Ele pode estar atrasado até lá**: a fonte da verdade é a listagem da pasta. Uma decisão sem linha aparece em "A classificar". Para mudar o módulo de uma decisão, mova a linha para a seção certa e regenere. O script não move decisão pelo título. **Módulo novo exige editar `MODULES` no script**: sem isso, a seção `##` nova é descartada, as decisões dela vão para "A classificar" e o script avisa. A decisão que criou este mecanismo é [`2026-10-11-indice-de-decisoes-gerado-por-script-fora-dos-prs`](2026-10-11-indice-de-decisoes-gerado-por-script-fora-dos-prs.md).
